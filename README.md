# ActiveLife - Weekly Interactive Fitness Tracker

ActiveLife is an interactive web application designed to help individuals plan, execute, and monitor their physical exercises across a structured 7-day week.

- **Batch:** 2024 Batch

## 🛠️ Technology Stack (Phase 2)
- **Frontend Structure:** HTML5
- **Styling & Components:** Custom CSS3 & Bootstrap 5
- **Client-Side Logic:** JavaScript (Vanilla JS)
- **Version Control:** Git & GitHub

## 🚀 Pages & Features
1. **Dashboard (`index.html`):** Weekly grid display for 7 days with quick logging status.
2. **Log Workout (`log-workout.html`):** Interactive workout logging form with real-time JavaScript validation for numeric inputs and required fields.
3. **Weekly Report (`weekly-report.html`):** Performance summary table with dynamic weekly progress goal status bar.

## 💻 How to Run Locally
1. Clone or download this repository.
2. Open `index.html` in any web browser.
